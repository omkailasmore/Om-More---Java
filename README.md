## 🚀 Getting Started

### Prerequisites

Install the Java Development Kit (JDK) and verify your installation:

```bash
java -version
javac -version
```

### Run a Program

1. Clone this repository:

   ```bash
   git clone https://github.com/omkailasmore/Om-More---Java.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Om-More---Java
   ```

3. Compile a Java file:

   ```bash
   javac Hello.java
   ```

4. Run the compiled program:

   ```bash
   java Hello
   ```

Replace `Hello` with the appropriate class name to run another program. Ensure the filename and public class name match where required.
